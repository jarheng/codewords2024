# codewords2024
## RMIT Studio codeWords
My project is inspired by the quote 'the net is anarchic and subversive' from James Wallbank's Lowtech Manifesto, the work reflects the internet's unpredictable and fluid nature. Through interactive elements on the webpage, the user can experience randomness while uncovering structured meanings, such as the keywords that have hidden definitions. My project should encourage users to explore and reveal layers of meaning as they interact. 

The webpage is built using Javascript with p5.js. Included within the webpage are interactive elements such as mouse hover effects, changing typography and colours, as well as clickable text and images. Letters will scatter and rearrange depending on the users input, while keywords will trigger specific actions. Background image will toggle based of user interactions, this should symbolise the contrast between chaos and order in relation to inspired text.
